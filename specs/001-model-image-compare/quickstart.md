# Quickstart：本地运行与验证

本地工作台已实现；本地测试与模拟浏览器验收见 [validation.md](validation.md)。五款真实模型接入尚未验收。

## 准备

在Windows仓库根目录使用Python3.12和uv。准备至少两张静态图片；真实接入时通过环境变量设置所选模型连接，参见[接口与配置契约](contracts/http-api.md)。不复制其他项目密钥。

执行：

```powershell
uv sync --group dev
uv run pytest -q
uv run hos-vlm-lab
```

测试默认使用fake/MockTransport，不读取真实密钥或访问真实模型。开发依赖已在pyproject定义。运行地址为 http://127.0.0.1:8000 。

## 本地自动验证

1. 网关请求捕获：共同文本和图片哈希一致；预算关闭时省略；无效/未知能力在HTTP前拦截，原始响应完整记录。
2. 数据与协议：合法事件、空列表、重复编码、非法JSON、截断、429、超时分别得到正确结果。缺失usage和费用显示未知。
3. SQLite临时目录测试：重试追加、request_id重复不重复调用、事务失败不调用、重启标记中断并保留历史图片。
4. 调度测试：受控阻塞响应制造停止/认领竞争，停止应答后没有新项发起；慢模型不阻断其他模型；无自动重试。

## 浏览器验证

在仓库根目录启动测试专用实例：

```powershell
uv run python -m tests.browser_app --data-dir .test-data/browser
```

入口只存在tests包，使用app工厂注入tests/fakes.py的网关和能力，不加载真实模型连接；所有出站HTTP拒绝，提供成功、空事件、延迟和失败的确定性结果。绑定127.0.0.1:8001，页面及模型名明确显示“模拟测试”。默认数据目录为临时目录；显式--data-dir保留到下次启动用于重启验收，禁止使用正式data目录；停止不自动删除用户指定目录。该入口不打包到正式应用，也不增加正式CLI的fake开关。

上传两图选两个fake提供方，在测试模式下运行，看到四个对应状态；逐项结果出现。修改提示词原图重跑，对照两轮并检查旧记录不变。模拟单项失败并手动重试，检查只新增该组合。停止余下任务，刷新及重启后检查历史保留。

另验证分批上传后合并21图创建轮次返回422且无记录/调用，1图及20图合法；首轮停止后重试失败项显示running而非stopping，重试结束保留历史stopped项，无活动批次重复停止不改变历史。

fake提供方仅测试环境注入，不伪装成真实模型结果，不作为生产候选模型配置。

## 显式真实验收

先补齐实际服务商及能力上限证据。选择一个可用模型、一张图片和兼容参数，手动运行，检查原始请求、视觉响应和usage。再进行spec SC-001的三图五模型验收；未配置或参数未取证的模型不得强行启用。

非思考temperature=0.6是候选基线，其他设置必须通过profile校验。记录实际模型身份、时间、参数、费用与失败。默认测试成功不代表真实模型、完整12组合或计费已经验证。


连接字段、可运行 profile、价格 JSON 与有效区间的完整说明见 [README](../../README.md)。程序不自动读取 .env；未配置或未取证模型在界面禁用。
