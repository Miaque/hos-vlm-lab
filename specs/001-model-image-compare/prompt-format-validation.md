# 最终提示词格式优化与验证（2026-09-12）

## 修改与文档依据

JSON 继续作为编辑/存储格式，新轮次的实际模型输入改为分节文本：任务 → 判定原则 → 通用要求 → 事件定义 → 补充上下文（如有）→ 输出。事件定义与用户指令完整保留；只省略来源与格式元数据，不增加模型专属隐藏消息。新文本增加先确认目标再核对条件、不得推断单帧无法证明的时间过程、区分输入目录与输出对象、提交前核对字段等约束。此方案是结合当前检测任务的工程选择，不是官方规定的唯一模板。

- [阿里云提示工程指南](https://help.aliyun.com/zh/model-studio/prompt-engineering-guide)：明确目标、分隔指令与数据、明确输出要求，并迭代验证。本次采用标题和中文字段标签，未使用要求模型公开逐步思考的指令。
- [Qwen 视觉接口](https://www.alibabacloud.com/help/zh/model-studio/vision)：支持用户消息中的文本与图片；本次保持现有 `text` / `image_url` 包装和统一图片字节。
- [Qwen3.6-27B 官方模型卡](https://huggingface.co/Qwen/Qwen3.6-27B)：建议在评测中规范输出；非思考推荐采样参数并非 temperature=0。本次选择页面现有的 0 温度基线隔离格式变量，不声称这是模型最优参数，不修改默认参数或加入 `/nothink`。
- [结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)：JSON Mode 是独立接口能力。本次不同时引入该变量，继续严格解析首次响应，不自动纠错或重试。

`rendered_prompt_text` 与 `prompt_renderer_version` 在事务提交前生成并冻结，保留原 `prompt_text`。所有模型共用冻结文本；重试直接复用，不随编辑器或程序升级改变。旧轮次没有新字段时沿用原始 JSON。页面结果及两轮对比展示实际发送文本。

## 真实调用范围与结果

使用已有 4 张统一处理后的 JPEG，不增加样本、不裁剪、不改事件定义。每种格式先运行全部图片，再复测首尾两张，因此每模型每格式最多 6 次。各模型内部串行、模型之间最多三路；相邻图片交替先测 JSON 或文本。相同参数：`temperature=0`、`max_tokens=4096`、`enable_thinking=false`。这只是请求参数，未独立验证上游如何应用思考开关。通过项目 Gateway 实际发送；未写入日常实验数据库。

| 模型槽位 | 原 JSON | 分节文本 | 结论 |
| --- | --- | --- | --- |
| qwen3.6-27b | 6/6 响应符合事件协议 | 6/6 响应符合事件协议 | 每个配对调用的事件编码集合一致 |
| qwen3.6-flash | 1 次网络失败 | 1 次网络失败 | 连续两次调用失败后停止该模型 |
| qwen3.8-flash | 1 次网络失败 | 1 次网络失败 | 连续两次调用失败后停止该模型 |

共发起 16 次调用：27B 成功 12 次，两个 Flash 共失败 4 次。Flash 没有收到 HTTP 响应；对共享入口只读连接检查在 `trust_env=true/false` 两种配置下均为 ConnectError，因此不能归因于提示词，也未通过禁用 TLS 验证规避问题。

27B 的 4 张图片结果（文件 ID 前缀）：`502d251f`、`5c5bce49`、`a2441ea7` 均返回空事件，`fc1dc80f` 返回 `city.order.animal_detected`。复测 `502d251f` 和 `fc1dc80f` 时，两种格式各自的事件集合均一致；新格式动物证据的措辞仍有小幅变化，不能称为逐字确定性。

| 27B 指标（服务返回值） | 原 JSON | 分节文本 |
| --- | --- | --- |
| 每次报告的输入 token | 5023 | 4423 |
| 6 次合计输出 token | 262 | 140 |
| JSON/事件协议成功率 | 6/6 | 6/6 |
| 平均耗时 | 2140 ms | 2018 ms |

新格式报告的输入 token 减少 600（约 11.95%），动物证据更简洁。耗时受调用顺序、缓存和服务负载影响，不能从该样本推断稳定加速。usage 由服务提供，未独立校准其图片 token 计数。按当时配置的价格与 usage 估算，12 次成功调用合计 0.177264 CNY；不是账单，失败调用是否计费未知。

**未证明准确率或稳定性提高。** 没有独立人工标注，4 张图片不足以覆盖 22 项事件，未计算 Precision/Recall/F1。当前证据支持新格式可用、输出更简洁、样本中未观察到事件集合退化；不能推出其他场景或 Flash 模型的效果。后续应使用独立标注的正负例与困难样本，再决定是否调整各事件判定规则。

本地证据位于 `.test-data/prompt-format-ab/`（Git 忽略）：`baseline.json`、`final-prompt.txt`、`metadata.json`、`results.jsonl`、`run.py`。元数据包含图片和提示词 SHA256；结果包含脱敏原始响应、参数、用量与价格快照。脚本会触发真实付费调用，不属于默认测试。
