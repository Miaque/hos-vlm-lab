# Feature Specification: 多模型图片对比调试

**Feature Branch**: 未创建（未配置分支钩子）

**Created**: 2026-09-11

**Status**: Ready for Planning

**Input**: 用户已确认的 [Demo 范围](../../docs/demo-scope.md)，术语见 [CONTEXT.md](../../CONTEXT.md)。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 同图多模型检测对比 (Priority: P1)

作为本地单人使用者，我上传一张或多张图片，选择模型，以相同提示词和可比参数逐图检测，比较检出事件及证据。

**Why this priority**: 直接支持观察模型识别差异，是最小可用闭环。

**Independent Test**: 两张图片、两个模型得到四个组合的独立结果，无需历史统计即可使用。

**Acceptance Scenarios**:

1. **Given** 模型已配置，**When** 选择两图与两模型运行，**Then** 每个模型分别检测每张图片，共四项；同一图片使用相同预处理内容和完整提示词，不合并多图推理。
2. **Given** 部分检测先完成，**When** 查看结果，**Then** 已完成项可查看，其他项显示状态，无需等待最慢项。
3. **Given** 合法检出事件，**When** 展示结果，**Then** 展示中文名称、编码、置信度、证据与原始输出，不画框或按置信度排名。
4. **Given** 空事件列表、非法格式或调用失败，**When** 展示结果，**Then** 分别显示未检出、格式错误、调用失败，不混为正常或确定不存在。
5. **Given** 未选图片或模型、上传文件不可解码，**When** 尝试运行，**Then** 明确指出输入问题，修正前不发起检测。

### User Story 2 - 编辑提示词和推理控制 (Priority: P1)

作为使用者，我修改完整提示词和四项控制，了解各模型参数兼容性，并查看实际使用的配置。

**Why this priority**: 防止隐藏参数差异导致对比失真。

**Independent Test**: 分别选择有效及不兼容设置，验证执行前提示和有效调用的输入快照。

**Acceptance Scenarios**:

1. **Given** 本地默认提示词，**When** 编辑包含多个事件的文本并运行，**Then** 各模型收到相同完整文本，系统不隐式补充或改写；恢复默认仅改变当前编辑内容。
2. **Given** 思考开关、THINKING_BUDGET、MAX_TOKENS、TEMPERATURE 四项控制，**When** 关闭思考，**Then** 预算禁用且不发送。
3. **Given** 某选定模型连接缺失、本地适配不支持参数组合或通用数值越界，**When** 尝试运行，**Then** 指出模型、参数和原因，在调整或取消选择前不启动本轮，不自动跳过模型或替换设置。
4. **Given** 设置有效，**When** 运行，**Then** 保存共用设置与各模型实际发送参数，提示词快照与发送内容一致，凭据不进入快照或结果页面。

### User Story 3 - 微调后对照历史 (Priority: P2)

作为使用者，我复用图片组修改提示词重跑，对照前后结果，重启后仍能查看历史。

**Why this priority**: 支持解释提示词变化带来的效果，避免覆盖旧结果。

**Independent Test**: 两轮同图不同提示词的记录可前后对照，重启后仍完整存在。

**Acceptance Scenarios**:

1. **Given** 已有一轮结果，**When** 修改提示词并复用图片组重跑，**Then** 创建新轮次，旧图片、参数、提示词和结果不变。
2. **Given** 同图两轮结果，**When** 选择对照，**Then** 同时看到模型、提示词、参数、事件与原文。
3. **Given** 已保存记录，**When** 移动原上传文件并重启，**Then** 历史图片及结果仍可查看，不依赖原文件位置。

### User Story 4 - 停止、重试和费用观察 (Priority: P2)

作为使用者，我能停止剩余任务、单项重试，并观察每次调用的耗时和费用。

**Why this priority**: 隔离失败，减少不必要调用，保留真实成本与协议遵循表现。

**Independent Test**: 使用含成功、失败和待开始项的一轮检测验证停止、单项重试与缺失费用展示。

**Acceptance Scenarios**:

1. **Given** 单项失败，**When** 其他项继续检测，**Then** 不受阻断，失败项保留第一次输出或错误，不自动纠正或重试。
2. **Given** 一个失败项，**When** 手动重试，**Then** 只重跑该图片与模型组合，沿用原输入快照，新增关联尝试，不覆盖旧记录。
3. **Given** 有待开始任务，**When** 停止生效，**Then** 不再发起待开始项，保留已完成结果，进行中项继续显示真实状态。
4. **Given** 返回实际用量，**When** 查看结果，**Then** 展示耗时、输入／输出 token；有可靠价格时展示估算费用、币种和计价依据，缺失项显示未知。

### Edge Cases

- 连接缺失或模型不可用：指出原因；允许只选一个可用模型，不要求五款全部配置。
- 思考预算与输出上限的组合约束在执行前校验，不仅校验单字段。
- 运行中修改输入只影响下一轮，不能改变已启动轮次。
- 空对象、非 JSON、重复或未允许编码、越界置信度、空或过长证据均为格式错误；保留原文，不转换为未检出。
- 输出截断后若不符合结果协议则显示格式错误；可获得的用量仍保存。
- 停止与完成同时发生时保留真实完成结果，不承诺撤销服务商已接收请求。
- 程序退出时未完成项，重启后标记中断，不自动恢复付费调用。
- 未知用量不等于零，估算费用不等于实际账单。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 面向本地单人使用，通过环境变量配置模型连接，不提供页面连接管理。候选为 deepseek-v4.1-flash、qwen3.6-flash、qwen3.8-flash、kimi 2.6、qwen3.6-27b；实际标识来自配置，至少一款可用即可调试。
- **FR-002**: 支持本地上传、预览、复用多张图片；无图片、无模型或无效图片时阻止运行并指出问题。
- **FR-003**: 每轮对每个选定图片与模型组合独立检测，同一图片的预处理内容一致，保留原图及处理后内容的可追溯身份。
- **FR-004**: 提供参考 hos-analysis 初筛契约的本地默认提示词及事件判定内容；完整文本可编辑、可含多个事件、可恢复默认，发送时不隐式补充或改写。
- **FR-005**: 页面提供思考开关、THINKING_BUDGET、MAX_TOKENS、TEMPERATURE；优先提供非思考基线，关闭思考不发送预算。
- **FR-006**: 执行前逐模型校验连接、通用数值与已知参数组合；无效配置阻止整轮。通过 LangChain 调用 OpenAI 兼容入口，不要求 PROFILE 或官方端点白名单；服务端能力/范围限制写入单项调用错误，不静默改写或重试。
- **FR-007**: 每轮冻结图片组、模型身份、完整提示词、允许检测事件、共用设置、实际发送参数和时间；凭据不保存到实验快照或页面输出。
- **FR-008**: 采用初筛 events 协议，每项仅有 canonical_event_code、confidence、evidence；编码属于本轮允许集合且不重复，置信度 0–1，证据 1–200 字符；空列表为合法未检出。
- **FR-009**: 按图片与模型展示中文事件名、编码、置信度、可见证据和原文；未返回只表示未检出，不增加 uncertain 字段、不等同确定不存在，不画框或直接用置信度排名。
- **FR-010**: 逐项展示待开始、进行中、成功、格式错误、调用失败、已停止或中断状态；单项失败不阻断其他已接纳检测。
- **FR-011**: 保存首次输出（若有）及错误，不自动纠正或重试；手动单项重试沿用原输入并新增关联记录。
- **FR-012**: 支持停止剩余任务，停止生效后不再发起待开始项，已完成结果不丢失，已发起项真实状态保留。
- **FR-013**: 每次尝试展示耗时、可获得的实际输入／输出 token、有依据的估算费用及币种和计价口径；缺失字段显示未知。
- **FR-014**: 修改输入重跑创建新轮次，支持同图跨轮次对照，不覆盖旧提示词、参数、结果和重试记录。
- **FR-015**: 本地保存历史图片、轮次及尝试，跨重启可查看；中断项不自动调用，允许用户手动重试。
- **FR-016**: 运行时不依赖 hos-analysis 或其他生产服务在线，默认提示词和事件内容本地可用；仅模型调用依赖所配置服务。

### Key Entities

- **图片／图片组**：原图、用于检测的视觉内容和身份，可跨轮次复用。
- **模型配置**：显示名称、实际模型身份、连接配置和能力；凭据与实验内容分离。
- **对比轮次**：冻结的图片、模型集合、提示词、允许事件与参数，是历史对照单位。
- **检测尝试**：一个图片与模型组合的执行状态、原始响应、错误、耗时、用量、费用和重试关联。
- **检出事件**：标准编码、中文名称、置信度与可见证据，不代表人工真值。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 五款模型及参数均验证可用时，三张图片得到 15 个组合的可见状态和结果；一款失败不阻断其余组合。
- **SC-002**: 验收中 100% 有效组合的同图视觉内容与完整提示词一致，实际参数可追溯；全部已知不兼容及非法设置在调用前拦截。
- **SC-003**: 合法检出、空事件、格式错误、调用失败四类验收样本均准确分类，失败不显示为未检出。
- **SC-004**: 同图两轮不同提示词可无需重新上传直接对照；重启后图片、输入快照与结果全部保留。
- **SC-005**: 含成功、失败及待开始项的轮次停止后不发起新项；单项重试仅新增一次对应尝试，原记录不变。
- **SC-006**: 所有尝试的用量及费用显示已知值或未知状态；已知费用验收样本按记录计价依据可复算一致。

## Assumptions

- 启动入口自动加载当前工作目录的 `.env`，已有环境变量优先；文件不存在时跳过，修改后需重启。
- 视频／多帧联合推理、画框、复核级联、标注平台、自动准确率统计、排行榜、多人账户不在本版范围。
- 候选名称不是模型能力证明；规划阶段核实实际服务商、视觉能力、参数映射和价格，配置齐全可发起请求，实际能力以真实接入验证为准。
- 编辑提示词以遵守既定 events 契约为目标，改变输出格式会显示格式错误。本轮允许事件集合与检测定义一致，具体编辑及提取方式留给技术设计。
- 图片大小、数量和并发上限在规划阶段确定并公开；不引入大规模评测性能承诺。
- 停止默认阻止未开始项，已开始项允许结束并保存，不承诺取消远端计费。
- 本地历史不自动过期，不自动恢复未完成调用；历史删除管理与导出不在本版新增范围。
- 耗时为单次模型调用开始到结束，不包括本地排队等待。
- 宪章目前为占位模板，不将示例视为有效原则。以已确认范围和项目协作约束为准。

连接配置：原四个模型共用 `VLM_BASE_URL` / `VLM_API_KEY`；`qwen3.6-27b` 独立使用 `QWEN36_27B_BASE_URL` / `QWEN36_27B_API_KEY`。各模型 ID 和价格独立配置；BASE_URL 包含服务路径前缀，程序追加 `/chat/completions`。
