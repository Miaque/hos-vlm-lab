# Demo 需求确认记录

状态：用户已确认整体范围，需求访谈完成，可进入技术设计；尚未实现。

## 已确认

- 核心目标：多个模型在相同图片、提示词和可比参数下检测，直观对比效果，并支持提示词微调。
- 支持本地上传一张或多张图片，每张图片独立检测，按“图片 × 模型”展示结果。
- 每轮共用一份提示词，允许包含多个检测场景。
- 图片组可复用，修改提示词后可直接重跑。
- 第一版展示判断、原因和原始输出，不画目标框。
- 保存每轮提示词、参数和检测结果，供修改前后对照。
- 单人使用；历史保存在本地，程序重启后仍可查看。
- 可比参数为模型共同支持且取值一致的参数；不支持项明确显示。
- 采用 hos-analysis 初筛 events 协议，展示中文名称、编码、置信度、可见证据和原始输出；未返回显示“未检出”，不增加 uncertain 字段。
- 置信度仅作辅助信息，不跨模型直接排名。
- 预置 hos-analysis 初筛提示词，允许编辑，每轮保存完整快照。
- 保留第一次输出；格式错误直接展示，手动重试另留记录，不自动纠正后覆盖原结果。
- 页面统一设置共同支持的参数并记录实际发送值。先做非思考模式基线，无法关闭或无法统一的差异明确标注。
- 展示每次调用耗时、实际 token 用量、估算费用及币种；缺失数据显示未知。
- 同一原图采用相同预处理后发送给各模型，保存可追溯信息，避免缩放和压缩差异影响对比。
- 第一版不引入复核、画框、自动准确率统计或生产服务依赖，各模型独立执行检测。
- 模型连接通过环境变量配置，不提供页面连接管理。当前候选模型为 deepseek-v4.1-flash、qwen3.6-flash、qwen3.8-flash、kimi 2.6、qwen3.6-27b；实际 API model ID 由环境配置指定，其中 qwen3.6-27b 使用独立 base_url 和 api_key。
- 页面提供是否开启思考、THINKING_BUDGET、MAX_TOKENS、TEMPERATURE 四项控制；具体 API 字段映射、支持范围和约束需按实际服务商核实，不能假定五款模型完全一致。
- 运行后结果逐项出现，单项失败不阻断其他检测；支持停止剩余任务、单独重试失败项，保留已完成结果。
- 完整提示词可编辑并可恢复默认；页面说明 events 输出协议，程序不隐式补充或改写用户提示词。
- 执行前逐模型校验参数支持情况和取值约束。不兼容时明确指出原因并阻止对应模型使用该设置运行，由用户调整参数或取消勾选；不静默忽略、不自动替换。
- 关闭思考时禁用 THINKING_BUDGET，且不向模型发送该参数。

领域术语见 [CONTEXT.md](../CONTEXT.md)。准确率排行榜、人工标注和批量统计不属于当前核心目标。

## 验收流程

以下流程由已确认需求推导，用于后续实现验收，当前未执行。

1. 用环境变量配置模型连接，在页面选择多个模型并上传多张图片。
2. 编辑共用提示词与四项推理控制，验证不支持项和非法值被明确指出，关闭思考后不发送预算。
3. 运行一轮检测，逐张图片核对各模型使用相同预处理内容和提示词，实际发送参数有记录，结果逐项出现。
4. 核对成功检出、空 events、格式错误和调用失败被分别呈现；可查看原文、耗时、usage 和费用，缺失值不显示为零。
5. 修改提示词后复用图片组重跑，能够对照前后轮次，旧提示词、参数与结果不被覆盖。
6. 单项失败不影响其余检测，手动重试保留独立记录；停止后不再启动剩余任务，已完成结果保留。
7. 重启程序后仍可查看历史图片和对应轮次结果。

## 设计阶段需核实的事实

- 五款模型在实际服务商下的视觉能力、API model ID、参数字段与有效范围，以及思考预算和输出上限的关系。
- usage 字段和计价口径。费用缺少可靠配置时显示未知。
- hos-analysis 默认提示词与事件判定契约如何整理为本地预置内容，运行时不依赖生产服务。

## hos-analysis 返回协议参考

用户要求参考该项目的大模型检测结果。已核对本地 `visual_event_clients.py` 的初筛提示词、输出模板和解析器，以及 `visual_event_models.py` 的 `ScreeningResponse`。

初筛返回 `events` 数组，每项仅有 `canonical_event_code`、`confidence`、`evidence`。置信度为 0–1，证据为 1–200 字符，同一编码仅返回一次，且必须属于本次允许判断的事件。

只返回有清晰可见证据支持的事件；无事件时返回 `{"events":[]}`。未返回可能表示不存在或证据不足，不能解释为明确否定；该协议没有逐事件 uncertain 状态。空对象、解析错误和调用失败不等于无事件。

另有独立事件复核协议（带 passed／event_not_present）和图片调试 API 包装（含 outcome、objects、diagnostics），与初筛原始返回不同。第一版已确认使用不带坐标的初筛协议；参考依据为源码，未调用真实模型。

连接配置：原四个模型共用 `VLM_BASE_URL` / `VLM_API_KEY`；`qwen3.6-27b` 独立使用 `QWEN36_27B_BASE_URL` / `QWEN36_27B_API_KEY`。各模型 ID、profile 和价格独立配置；BASE_URL 包含服务路径前缀，程序追加 `/chat/completions`。
